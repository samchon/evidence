# Discussion

Establish the topic, constraints, known evidence, and unresolved decisions. Discussion explores a question; it does not authorize implementation, issue publication, or changes to a PR.

Keep substantial discussion notes under `.discussions/<topic>` and preserve existing records. Separate observed facts, inferences, proposals, and decisions. Link primary sources and reproducible experiments rather than relying on an asserted conclusion.

If the user explicitly requests a team discussion, apply the multi-agent skill and give each participant a self-contained brief without a preferred answer. Record material positions and revisions faithfully; do not report reconstructed summaries as verbatim transcripts.

Conclude with supported agreements, unresolved disagreements, and the decisions needed for the user's goal. Follow a user-specified number of rounds or participants; otherwise use only enough discussion to settle the actual question. Continue into implementation only when authorized.
