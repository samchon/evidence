# Parallel Review

Give independent reviewers the entire declared change and the same baseline. Parallel reviewers add independent reasoning; splitting files between them is not equivalent to a complete independent review.

Keep reviewers read-only. They report candidate defects with evidence, locations, consequences, and verification, and do not post reviews or edit code independently.

The lead checks every finding against the implementation and contract, combines duplicates, rejects unsupported claims, and applies verified corrections. Review the complete integrated result after changes. Distinguish actual agreement from reviewers merely accepting a supplied conclusion.
