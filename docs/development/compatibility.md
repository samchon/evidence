# `@ttsc/evidence` compatibility

The compatibility baseline is [`@ttsc/evidence` at `14a22f077caf23f1bfb8a97b3d9db765912074ef`](https://github.com/samchon/ttsc/tree/14a22f077caf23f1bfb8a97b3d9db765912074ef/packages/evidence). This ledger records which observable contracts the standalone checker preserves, translates for declared-source analysis, or defers because they require the TypeScript compiler.

The status terms have exact meanings:

- **Preserved** keeps the same author-visible obligation or failure rule.
- **Translated** keeps the purpose while changing identity, loading, or configuration to fit a standalone file checker.
- **Deferred** is outside the current compatibility claim and must not be approximated as a complete result.
